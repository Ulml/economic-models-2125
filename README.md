# Modèles Économiques jusqu'en 2125

Ce repo contient les scripts Python développés pendant la conversation sur les projections économiques mondiales, l'impact de l'IA, et le pouvoir d'achat d'un retraité.

## Scénarios
- **Optimiste** : Forte croissance grâce à l'IA
- **Réaliste** : Croissance ralentie mais positive
- **Pessimiste** : Risque de stagnation ou déclin dû à la perte de demande

Les codes sont corrigés et exécutables.
